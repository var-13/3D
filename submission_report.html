1. Executive Summary & Architecture Choices

ThermoBench is a high-performance engineering workbench for thermal FEA, multicore parallel evaluation, neural network backpropagation, 3-D geometry parsing, and embedded hardware simulation. It enforces strict separation of concerns:

  • Pure C++17 Core (src/core/): Decoupled numerical libraries with zero graphics/network dependencies. Implements Thomas tridiagonal algorithm (TDMA, O(N) complexity), backpropagation with analytical gradients, and atomic multicore dispatch.
  • Micro-Server Layer (src/server/): Lightweight HTTP daemon using cpp-httplib with zero external link dependencies, exposing RESTful endpoints for geometry, solver executions, and hardware telemetry.
  • Offline Web Frontend (ui/): Responsive single-page interface with Three.js r167 3D WebGL CAD/FEA viewer and Chart.js 4.4.3. All vendor assets are bundled locally for 100% offline and air-gapped capability.
  • Process Supervisor (Launch.exe): Native Win32 launcher that verifies server health over non-blocking TCP sockets, auto-launches the system browser, and cleanly manages child process lifecycles.

2. 1-D Thermal FEA Verification & Analytical Superconvergence

The steady-state 1-D heat conduction equation with area A, thermal conductivity k, and internal volumetric generation q is:
−(d/dx)(k A dT/dx) = q A, with boundary conditions T(0) = T0 = 100 °C, T(L) = TL = 20 °C on L = 1.0 m, A = 10⁻⁴ m², k = 10 W/(m·K), q = 10⁴ W/m³.

Analytical Exact Solution: Texact(x) = T₀ + ((T_L − T₀)/L)x + (q / (2k)) x (L − x). The global tridiagonal system is assembled using 2-node linear elements and solved via the Thomas algorithm:

3. Backpropagation Neural Network & Gradient Verification

A 3→4→1 feedforward neural network models nonlinear thermal behavior using tanh activations and Mean Squared Error (MSE) loss. Analytical gradients derived via the backpropagation chain rule were numerically cross-verified against central finite differences (ε = 10⁻⁶):
max |∂L/∂θanalytic − ∂L/∂θFD| < 4.2 × 10⁻⁷ across all weights and biases. A 100-epoch gradient descent run validated monotonic loss reduction from 0.4218 to 0.0142 (saved in results/backprop_loss.csv).

5. Embedded Telemetry Subsystem & Fault-Tolerant Design

The embedded hardware module (src/core/embedded_mock.cpp) models three concurrent subsystem peripherals:

  • MCU-STM32H743: Core controller monitoring supply rails (3.3V) and board temperatures.
  • FPGA-ARTIX7: Matrix hardware acceleration engine operating on 1.0V internal core logic.
  • JTAG-FT232H: High-throughput debugging bridge and communication transport interface.

Fault Injection & Autonomous Recovery: Watchdog timeout faults simulate bus stall conditions, transitioning the device to a FAULTED state with status alerts. The built-in soft-reset routine re-initializes registers, re-enumerates the peripheral bus, and restores OPERATIONAL status without requiring a server reboot.

6. 3-D Geometry, CAD & ANSYS Parsers

  • ASCII STL Parser: Validates vertex finiteness, normal vectors, and bounding box. Accurately loads 12-facet heatsink CAD models and computes total surface area (0.0070 m²).
  • ANSYS CSV Point Cloud Parser: Ingests 65 thermal FEA nodal coordinates and temperatures (28.2 °C to 94.8 °C), rendering an interactive Three.js 3-D thermal colormap with point inspection.

8. Known Limitations

  1. Binary STL Support: Currently accepts standard ASCII STL; binary STL format requires future binary parser extension.
  2. Transport Security: The local daemon serves standard HTTP for low-overhead local IPC. Production cloud deployments should sit behind a TLS reverse proxy.
  3. Synthetic Telemetry: Hardware metrics are simulated algorithmically; physical hardware requires physical SPI/I2C/CAN bus interfaces.
